WIZE

Smarter Patient Communication. Simplified Hospital Operations.

WIZE is a WhatsApp-based hospital automation platform, not just a chatbot. Patients start with a short WhatsApp chat, then move into a rich hospital app for services, doctors, appointments, maternity, diagnostics, enquiries and feedback. Try it on the phone.

What is real and what is simulated

Real WhatsApp Cloud APIReply buttons (max 3), CTA URL buttons that open a hosted web app in WhatsApp’s in-app browser, native WhatsApp Flows (JSON-defined, fixed components), webhooks and template reminders.
Simulated in this demoThe WhatsApp chat frame. The hospital app is a normal web page in a phone sheet (the CTA URL pattern), not a native Flow. API data is mock until CFG.MOCK is set to false.
